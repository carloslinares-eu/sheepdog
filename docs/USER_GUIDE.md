# Sheepdog user guide

Sheepdog is not released yet. This guide grows with each milestone in
[RELEASE_PLAN.md](RELEASE_PLAN.md); the complete version arrives with v0.9.

## Installing

- **Windows:** download `Sheepdog-X.Y.Z-win64.zip`, unpack it anywhere and run `sheepdog.exe`.
  The builds are not code-signed, so Windows SmartScreen may show a warning the first time.
- **Linux:** download `Sheepdog-X.Y.Z-x86_64.AppImage`, make it executable and run it.

## Command line

`sheepdog-cli --version` prints the version. More commands follow from v0.1.0.
